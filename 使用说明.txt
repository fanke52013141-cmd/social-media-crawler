============================================================
                资讯采集中心 · 便携版 使用说明
============================================================

【这是什么】
一个免安装、可离线运行的本地资讯采集工作台。内置 Python 运行环境与
浏览器内核，无需在电脑上安装 Python，解压后双击即可使用。

【系统要求】
- Windows 64 位系统（Win10 / Win11 及对应的 Server 版本）
- 无需联网安装任何组件，可在完全离线 / 内网环境运行
- 采集动作本身需要能访问目标平台（内网隔离环境无法访问外网平台）

【目录结构】
  启动.bat   双击这个启动软件
  runtime\   内置 Python 运行环境（请勿删除/改名）
  browser\   内置浏览器内核（请勿删除/改名）
  app\       程序与你采集的数据（data 目录）

【使用步骤】
1. 双击「启动.bat」，会自动在后台启动服务并打开网页工作台
   （地址 http://127.0.0.1:8765，也可在浏览器手动输入）。
2. 首次使用需登录：选择平台后开始采集，屏幕会弹出一个小的二维码
   图片窗口，用手机 App 扫码登录即可；登录态会保存在本机，之后
   无需重复扫码。
3. 采集方式：
   - 关键词采集：在搜索框输入关键词，多个用逗号分隔，回车即开始。
     全角逗号、分号、空格也会自动拆分为多个词逐词搜索。
   - 链接采集：切换到链接模式，粘贴帖子链接，可抓取评论、子评论
     以及评论人的小红书号。
   - 每日定时任务自动采集「当天 00:00 至 23:59」发布的内容，窗口随日期
     滚动（可切换为近 N 天滚动）；单次/立即任务用选定的固定日期区间。
   - 多平台任务中某个平台登录失效时，自动跳过该平台并继续采集其余平台，
     不会整体停摆；卡片会注明哪个平台被跳过。
4. 采集结果在页面按发布时间倒序展示，支持时间筛选；点「导出」可
   下载 Excel（含「内容」「评论」两个工作表，评论含小红书号）。
5. 采集中可点「停止」，会终止进程并保留已经采集到的数据。

【静默采集（不占屏幕）】
浏览器全程在后台无头运行，不会弹出浏览器窗口、不抢占你的屏幕；
只有在登录失效需要扫码时，才会弹出一个小的二维码图片窗口。
想亲眼观察浏览器画面时，可打开工作台顶栏「显示浏览器窗口」开关
（下次启动浏览器生效，设置会记住）。

【已内置的反爬 / 风控机制】
- 单线程采集，请求之间加入随机间隔，模拟真人操作节奏；
- 访问用户主页解析小红书号时，额外加入随机等待；
- 请求失败采用「指数退避 + 随机抖动」自动重试，避免连续硬撞；
- 小红书启用风控熔断：首次出现限流(429)/账号安全限制(300011)/人机验证时
  立即停止本轮采集，并阶梯冷却（24 小时内再犯：30 分钟→2 小时→24 小时），
  绝不在风控窗口内反复硬重试（硬重试会把限制升级为警告/封禁）；
- 小红书数据请求带真实浏览器 TLS 指纹（curl_cffi），降低被识别为脚本的风险；
- 浏览器视窗在常见桌面分辨率中随机，降低固定指纹特征；
- 注入 stealth 脚本，弱化自动化特征；
- 遇到滑块/人机验证(HTTP 461/471)时，自动切换到有头模式弹出浏览器，
  你手动完成验证后，程序自动同步登录态并继续采集，不会再因验证码
  反复重试而崩溃；若 150 秒内未完成则明确提示。
注意：以上机制只能「降低」风险，无法保证完全不被限制。请务必控制
采集量与频率，登录失效时及时重新扫码，不要长时间高强度采集。

【常见问题】
- 双击后网页没打开：稍等片刻，或手动访问 http://127.0.0.1:8765。
- 提示登录已过期：重新开始一次采集，扫码重新登录即可。
- 采集时突然弹出浏览器要求滑块：这是触发了人机验证，在弹出的窗口里
  手动完成验证即可，程序会自动继续，无需重新采集。
- 端口被占用：如本机已有其他程序占用 8765，请先关闭该程序。
- 请勿移动或重命名 runtime、browser 目录，否则软件无法启动。
